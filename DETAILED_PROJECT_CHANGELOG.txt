========================================================================
DEEP DIVE CHANGELOG: GRC PLATFORM EXPERT MODIFICATIONS
========================================================================
(This is a highly detailed, technical explanation of EVERY logical feature 
added and changed in the code since downloading the original GitHub base. 
Specially highlighted is today's architecture and logic).

------------------------------------------------------------------------
1. DATABASE & SECURITY LAYER (Backend Models & Migrations)
------------------------------------------------------------------------
* The original GitHub version was missing crucial fields to implement Auditor timers and 2FA. We modified the `UserProfile` table and created multiple database migrations (`0005`, `0006`, `0007`).
* Added `totp_secret` (VARCHAR) to store the physical cryptographic hash for Two-Factor Authentication.
* Added `password_changed_at` (DATETIME) to strictly determine if an admin is using their insecure 'default' password, triggering warnings.
* Added `account_expiry_date` (DATETIME) for Auditors to allow auto-revocation.

------------------------------------------------------------------------
2. MANAGE ADMINISTRATORS LOGIC (Today's Frontend Focus)
------------------------------------------------------------------------
We rewrote `ManageAdmins.jsx` to be a complex, multi-layered dashboard rather than a simple grid:
* Auditor Expiry Integration (`InviteModal`): 
  - REMOVED the basic "expiry hours" math logic.
  - BUILT a native `datetime-local` browser calendar integration. 
  - LOGIC: Used `timezoneOffset` calculations to dynamically block past dates, letting the Super Admin pick the exact timestamp the auditor's compliance access vanishes.
* Regenerate Credentials Interceptor (`RegenerateModal`): 
  - Original problem: Regenerating blindly nuked credentials and locked users out if their email was compromised.
  - NEW LOGIC: A dialog box now intercepts the button click, auto-fills their current email, and asks you if you want to overwrite it with a new "Target Delivery Email" before safely generating the cryptographic password and QR Code.
* Off-Canvas Side Panel (`ViewDetailsPanel`):
  - Created a smooth animated side-slider that maps user avatars.
  - Automatically calculates an active `setInterval` JavaScript countdown, tracking the exact days/hours/minutes left until the Auditor expires, displaying it physically in the UI.

------------------------------------------------------------------------
3. THE NEW SETTINGS ARCHITECTURE (Settings.jsx)
------------------------------------------------------------------------
We fundamentally isolated User settings from Global Configs into 3 Tabs:
* My Identity & Security Tab:
  - Avatar Logic: Injected an invisible `<input type="file">`. When clicked, it captures the image blob and displays it in real-time using `URL.createObjectURL()`.
  - Saved via Axios overriding default JSON structures to use `FormData` (multipart/form-data payload) so physical `.jpg`/`.png` bytes are passed.
  - Password Visibiity: Wrote complex state conditions (`showOldPwd`, `showNewPwd`, `showConfirmPwd`) attached to Lucyde "Eye" icons. This swaps the input fields securely back and forth between `<input type="password">` and `<input type="text">` to stop mistyped blockages.
* Global System Threshold Tab:
  - Linked active database settings (like `passing_score_threshold`) to auto-save `<input type="range">` sliders that automatically deploy to `/api/settings/` on mouse release.

------------------------------------------------------------------------
4. BACKEND INTEGRATION & SMTP PIPELINES (Python/Django)
------------------------------------------------------------------------
* Advanced Email Threading (`views.py`):
  - Created `_send_invite_email()`: Uses Python's `MIMEMultipart("related")` to actually embed the TOTP QR Code natively using `<img src="cid:qrcode">` directly inside HTML so the admin's email client doesn't block the image!
  - Created `_send_reminder_email()` (Today): Hard-wired the bell 🔔 icons on the frontend to explicitly trigger this background Python thread. It successfully executes SMTP TLS handshakes and sends formalized "Change your password" notices.
* Dashboard Metrics Overhaul (`DashboardSummaryView`):
  - LOGIC: The "Mini Audit Log" was fetching absolutely everything (logins, logouts, clicks).
  - FIXED: Appended `.filter(module__icontains="Policy")` explicitly, forcing the SQL table to ONLY spit out records validating actual compliance policy modifications.
* Unblocked Static Storage (`urls.py` & `settings.py`):
  - Fixed a major glitch where uploaded Avatars were hitting 404 blockages. 
  - Exposed `STATIC_URL` and `MEDIA_URL` into `urlpatterns` conditionally, securely routing React's dashboard previews to physical Django file pathways.

------------------------------------------------------------------------
5. UI / UX DYNAMICS (Dark Mode)
------------------------------------------------------------------------
* Hand-coded `.dark` variables deeply into `index.css` overrides.
* Patched `DashboardLayout.jsx` background elements where hardcoded colors overrode OLED capabilities, utilizing explicit Tailwind syntax combinations (`bg-[#f4f6f9] dark:bg-black`).
