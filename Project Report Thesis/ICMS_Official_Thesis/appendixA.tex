\chapter{User Manual}

\section{Purpose}
The Intelligent Security Compliance Management System (ISCMS) is a Governance, Risk, and Compliance (GRC) platform. It automates the auditing process by mapping technical telemetry from the Wazuh SIEM to regulatory frameworks, reducing the need for manual spreadsheet-based assessments.

\section{System Requirements}
The following requirements are for system operation:
\begin{itemize}
    \item \textbf{Device:} Workstation with a minimum 1080p resolution recommended for viewing data tables.
    \item \textbf{Web Browser:} Google Chrome v100+, Mozilla Firefox v100+, or Microsoft Edge.
    \item \textbf{Network:} Intranet or VPN access to the ISCMS environment.
    \item \textbf{Authentication:} Authenticator Application (e.g., Google Authenticator, Authy) for TOTP Two-Factor Authentication.
\end{itemize}

\section{System Access}
\begin{itemize}
    \item Navigate to the ISCMS URL in a supported web browser.
    \item Enter the registered email and password.
    \item Provide the 6-digit TOTP code from the authenticator application.
    \item Access the dashboard corresponding to the assigned role (Superadmin, Admin, or Auditor).
\end{itemize}

\textbf{Step 4 -- Telemetry Mapping Configuration (Superadmins)}
\begin{itemize}
    \item Use the "Mapping Configuration" portal.
    \item Link Wazuh Security Configuration Assessment (SCA) Rule IDs to GRC controls.
    \item Save the mapping to categorize incoming SIEM events.
\end{itemize}

\textbf{Step 5 -- Wazuh Telemetry Synchronization}
\begin{itemize}
    \item The system polls the Wazuh manager in the background.
    \item Administrators can click "Trigger Manual Sync" on the Scans page for an immediate update.
    \item View synchronization logs to verify data ingestion.
\end{itemize}

\textbf{Step 6 -- Endpoint Monitoring}
\begin{itemize}
    \item Use the "Endpoints" view to monitor specific systems.
    \item Select a workstation or server to view its compliance score and failed security checks.
\end{itemize}

\section{Logout}
\begin{itemize}
    \item Click the user profile icon in the navigation shell.
    \item Select "Logout" to end the session and clear browser storage.
\end{itemize}

\section{Support}
\begin{itemize}
    \item For credential recovery or 2FA resets, contact the IT Security Administrator.
    \item For Wazuh agent connectivity issues, contact the SIEM infrastructure team.
\end{itemize}

\section{Note}
The ISCMS platform automates compliance visibility and reporting based on SIEM telemetry. It highlights security gaps and maps them to regulatory controls, but resolving those gaps requires administrative action on the affected endpoints.
