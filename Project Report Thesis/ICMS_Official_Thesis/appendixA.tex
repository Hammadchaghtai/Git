\chapter{User Manual}

\section{Purpose}
The Intelligent Compliance Management System (ICMS) is a Governance, Risk, and Compliance (GRC) platform. It automates the auditing process by mapping technical telemetry from the Wazuh SIEM to regulatory frameworks, reducing the need for manual spreadsheet-based assessments.

\section{System Requirements}
The following requirements are for system operation:
\begin{itemize}
    \item \textbf{Device:} Workstation with a minimum 1080p resolution recommended for viewing data tables.
    \item \textbf{Web Browser:} Google Chrome v100+, Mozilla Firefox v100+, or Microsoft Edge.
    \item \textbf{Network:} Intranet or VPN access to the ICMS environment.
    \item \textbf{Authentication:} Authenticator Application (e.g., Google Authenticator, Authy) for TOTP Two-Factor Authentication.
\end{itemize}

\section{System Access}
\begin{itemize}
    \item Open a web browser and navigate to the ICMS URL.
    \item Enter the registered email and password.
    \item Enter the 6-digit TOTP code from the authenticator application.
    \item The system directs the user to the Dashboard based on the assigned role (Superadmin, Admin, or Auditor).
\end{itemize}

\section{Main User Steps}

\textbf{Step 1 -- Authentication and Role Verification}
\begin{itemize}
    \item Users authenticate through the login portal.
    \item The system verifies the session and displays the interface corresponding to the user privilege level.
\end{itemize}

\textbf{Step 2 -- Dashboard Overview}
\begin{itemize}
    \item Use the Home Dashboard to view the organizational compliance posture.
    \item View the compliance percentages for active frameworks.
    \item Use the theme switcher in the navigation bar to toggle between Light and Dark modes.
\end{itemize}

\textbf{Step 3 -- Framework and Control Management (Admins)}
\begin{itemize}
    \item Use the "Frameworks" tab to view regulatory standards.
    \item Select a framework to view its clauses and technical controls.
\end{itemize}

\textbf{Step 4 -- Telemetry Mapping Configuration (Superadmins)}
\begin{itemize}
    \item Use the "Mapping Configuration" portal.
    \item Link Wazuh Security Configuration Assessment (SCA) Rule IDs to GRC controls.
    \item Save the mapping to categorize incoming SIEM events.
\end{itemize}

\textbf{Step 5 -- Wazuh Telemetry Synchronization}
\begin{itemize}
    \item The system polls the Wazuh manager in the background.
    \item Administrators can click "Trigger Manual Sync" on the Scans page for an immediate update.
    \item View synchronization logs to verify data ingestion.
\end{itemize}

\textbf{Step 6 -- Endpoint Monitoring}
\begin{itemize}
    \item Use the "Endpoints" view to monitor specific systems.
    \item Select a workstation or server to view its compliance score and failed security checks.
\end{itemize}

\textbf{Step 7 -- Automated Audit Report Generation}
\begin{itemize}
    \item Use the "Reports" module to generate documentation.
    \item Select the regulatory framework and date range.
    \item Click "Generate PDF" to download the audit report.
\end{itemize}

\textbf{Step 8 -- System and User Management}
\begin{itemize}
    \item Superadmins use "Manage Users" to provision accounts and assign roles.
    \item Configure SMTP alerts in System Settings for email notifications upon compliance failure.
\end{itemize}

\section{Logout}
\begin{itemize}
    \item Click the user profile icon in the navigation shell.
    \item Select "Logout" to end the session and clear browser storage.
\end{itemize}

\section{Support}
\begin{itemize}
    \item For credential recovery or 2FA resets, contact the IT Security Administrator.
    \item For Wazuh agent connectivity issues, contact the SIEM infrastructure team.
\end{itemize}

\section{Note}
The ICMS platform automates compliance visibility and reporting. The system provides mappings based on SIEM telemetry and functions as an orchestration and governance tool. Maintaining compliance requires remediation of identified vulnerabilities. The ICMS highlights security gaps, but administrative action on the endpoints is necessary to resolve them.
