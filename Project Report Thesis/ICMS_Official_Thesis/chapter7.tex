\chapter{Conclusions}

The Intelligent Security Compliance Management System (ISCMS) shows that connecting Security Information and Event Management (SIEM) telemetry to a Governance, Risk, and Compliance (GRC) engine can automate the auditing lifecycle. The platform links regulatory frameworks to endpoint security through a deterministic mapping algorithm. Translating Wazuh Security Configuration Assessment (SCA) alerts into ISO 27001 controls allows an organization to maintain a continuous compliance posture.

Several engineering conclusions follow from the implementation. A hybrid database schema, using PostgreSQL's \texttt{JSONField} for Wazuh logs alongside relational tables for user roles and frameworks, can ingest SIEM data while maintaining ACID compliance. Testing confirmed that offloading I/O-bound operations, such as API polling and PDF generation, to a Celery worker queue prevents API gateway timeouts. The deployment also shows that stateless JSON Web Tokens (JWT) combined with a React Context provider enforce Role-Based Access Control (RBAC) without server-side session management overhead.

Future work could extend this project toward an enterprise-grade product. Technical improvements include replacing the REST API polling model with a WebSocket or Webhook-driven architecture to reduce latency and support real-time compliance recalculations. The containerized topology could also be migrated from Docker Compose to Kubernetes for horizontal scaling. A longer-term goal is to open-source the codebase, which would enable community contributions and additional integration modules for SIEM providers like Splunk or Elastic Security, while expanding the library of supported regulatory frameworks.
