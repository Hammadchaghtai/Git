\chapter{Conclusions}

The development and deployment of the Intelligent Compliance Management System (ICMS) successfully demonstrated that integrating raw Security Information and Event Management (SIEM) telemetry directly into a centralized Governance, Risk, and Compliance (GRC) engine can automate the traditionally manual auditing lifecycle. Originating as an industrial collaborative project, the platform bridged the gap between theoretical regulatory frameworks and practical endpoint security by engineering a deterministic mapping algorithm. This implementation proved that by translating Wazuh Security Configuration Assessment (SCA) alerts into structured ISO 27001 controls, an organization can maintain a continuous, mathematically verifiable compliance posture rather than relying on point-in-time assessments.

Several critical engineering conclusions were drawn from the architectural implementation. First, the integration of a hybrid database schema---utilizing PostgreSQL's \texttt{JSONField} for unstructured Wazuh logs alongside strict relational tables for user roles and frameworks---provides an efficient mechanism for ingesting unpredictable SIEM data without compromising the ACID compliance of the core application. Second, the evaluation phase confirmed that offloading heavy I/O-bound operations, such as API polling and multi-page PDF generation, to a distributed Celery worker queue is a mandatory architectural pattern to prevent API gateway timeouts in high-density enterprise environments. Finally, the deployment demonstrated that stateless JSON Web Tokens (JWT) combined with a React Context provider offers an efficient mechanism for enforcing strict Role-Based Access Control (RBAC) across a Single Page Application without incurring server-side session management overhead.

Moving forward, there are several avenues through which this industrial project can be expanded into a polished, enterprise-ready product. A primary technical enhancement would involve transitioning the SIEM integration from periodic REST API polling to a persistent WebSocket or Webhook-driven streaming architecture, which would eliminate latency and enable true real-time compliance state recalculations. Additionally, the system's containerized topology can be upgraded from standard Docker Compose to Kubernetes manifests to support horizontal scaling and high availability across distributed cloud clusters. The long-term vision for the ICMS platform is to refine its core orchestration engine and release it as an open-source software solution. By open-sourcing the codebase, the platform can foster community-driven development, allowing external engineers to contribute integration modules for additional SIEM providers, such as Splunk or Elastic Security, and continuously expand the library of supported global regulatory frameworks.
