\chapter*{Abstract}
Manual security auditing and static compliance mapping create blind spots that leave enterprise infrastructure vulnerable to configuration drift. Existing Governance, Risk and Compliance (GRC) policies do not consider endpoint telemetry, resulting in high administrative costs and unreliable security observations. This project combines an Intelligent Compliance Management System (ICMS) that centrally automates continuous controls monitoring. Developed as an industrial collaboration, the platform integrates with the Wazuh Security Information and Event Management (SIEM) system to ingest Security Configuration Assessment (SCA) logs. A deterministic mapping algorithm translates raw technical events into verifiable regulatory controls, which allows for continuous compliance tracking against standards like ISO/IEC 27001. The system uses an N-tier architecture. A React Single Page Application (SPA) handles the presentation layer and communicates with a Django REST Framework API. To prevent main-thread blocking during SIEM polling and PDF report generation, the system offloads intensive I/O operations to an asynchronous Celery and Redis worker tier. Data persistence is managed via PostgreSQL, using a hybrid schema that combines relational constraints for Role-Based Access Control (RBAC) with JSON fields for telemetry storage. Platform security relies on stateless JSON Web Tokens (JWT) and Time-based One-Time Password (TOTP) two-factor authentication. Testing confirmed the platform works as intended. The asynchronous tier processed high-density endpoint synchronizations with an average API latency under 150ms. The mapping engine maintained data integrity even during collision attempts. The ICMS shows that replacing manual audits with continuous SIEM integration establishes a verifiable compliance posture and reduces the burden of organizational audits.
