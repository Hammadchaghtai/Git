\chapter*{Abstract}
Manual security auditing and static compliance mapping leave gaps that expose enterprise infrastructure to configuration drift. Existing Governance, Risk and Compliance (GRC) tools ignore endpoint telemetry, which raises administrative costs and produces unreliable security assessments. This project presents the Intelligent Security Compliance Management System (ISCMS), a platform that automates continuous controls monitoring. The system integrates with the Wazuh Security Information and Event Management (SIEM) engine to ingest Security Configuration Assessment (SCA) logs. A deterministic mapping algorithm translates raw technical events into verifiable regulatory controls, enabling continuous compliance tracking against standards such as ISO/IEC 27001. The system follows an N-tier architecture. A React Single Page Application (SPA) serves the presentation layer and communicates with a Django REST Framework API. To avoid blocking the main thread during SIEM polling and PDF report generation, the system offloads I/O operations to a Celery and Redis worker tier. PostgreSQL stores all data using a hybrid schema that pairs relational constraints for Role-Based Access Control (RBAC) with JSON fields for raw telemetry. Authentication combines stateless JSON Web Tokens (JWT) with Time-based One-Time Password (TOTP) two-factor verification. Testing confirmed the platform operates correctly. The asynchronous tier processed concurrent endpoint synchronizations with an average API latency under 150ms, and the mapping engine preserved data integrity during collision attempts. These results show that replacing periodic manual audits with continuous SIEM integration produces a verifiable compliance posture and cuts the overhead of organizational audits.
