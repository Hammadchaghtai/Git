\chapter*{Abstract}
Manual security auditing and static compliance mapping create temporal blind spots, leaving enterprise infrastructure vulnerable to configuration drift between assessment cycles. Traditional Governance, Risk, and Compliance (GRC) processes often remain disconnected from actual endpoint telemetry, resulting in high administrative overhead and inaccurate security postures. This project presents the Intelligent Compliance Management System (ICMS), a centralized orchestration platform designed to automate continuous controls monitoring. Originating as an industrial collaborative project, the platform integrates directly with the Wazuh Security Information and Event Management (SIEM) system to ingest unstructured Security Configuration Assessment (SCA) logs. By implementing a deterministic mapping algorithm, the ICMS translates raw technical events into verifiable regulatory controls, enabling continuous compliance tracking against standards such as ISO/IEC 27001.

The system is engineered using an N-tier architecture. A React Single Page Application (SPA) serves as the presentation layer, communicating with a Django REST Framework API. To prevent main-thread blocking during high-volume SIEM polling and comprehensive PDF report generation, intensive I/O operations are offloaded to an asynchronous Celery and Redis worker tier. Data persistence is managed via PostgreSQL, utilizing a hybrid schema that combines rigid relational constraints for Role-Based Access Control (RBAC) with dynamic JSON fields for variable telemetry storage. Platform security is enforced through stateless JSON Web Tokens (JWT) and Time-based One-Time Password (TOTP) two-factor authentication. 

Comprehensive functional and non-functional testing confirmed the platform's operational viability. The asynchronous tier successfully processed high-density endpoint synchronizations while maintaining an average API latency of under 150ms, and the mapping engine maintained strict referential integrity against collision attempts. The ICMS demonstrates that replacing point-in-time manual audits with continuous, mathematically verifiable SIEM integration establishes a deterministic compliance posture and significantly reduces organizational audit fatigue.
